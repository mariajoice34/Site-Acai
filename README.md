# site de Açaí

Site desenvolvido para simular o sistema de pedidos de uma açaiteria, permitindo que o cliente escolha produtos, personalize seu pedido, utilize um carrinho de compras e finalize o atendimento pelo WhatsApp.

## Funcionalidades

- Visualização dos produtos
- Personalização dos pedidos
- Carrinho de compras
- Adição e gerenciamento de produtos no carrinho
- Cálculo automático dos valores
- Finalização do pedido
- Integração com WhatsApp

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript

## Sobre o projeto

O projeto foi desenvolvido com o objetivo de praticar desenvolvimento web por meio da criação de uma aplicação voltada para uma situação real de comércio.

A aplicação permite que o usuário monte seu pedido de forma interativa, acompanhe os produtos adicionados ao carrinho e utilize o WhatsApp para continuar o atendimento.

## Conceitos praticados

Durante o desenvolvimento foram trabalhados conceitos como:

- Estruturação de páginas com HTML
- Estilização com CSS
- Manipulação de elementos com JavaScript
- Eventos e interatividade
- Manipulação de dados do carrinho
- Cálculo de valores
- Navegação entre páginas
- Integração com serviços externos

## Estrutura principal

- `index.html` — página principal do site
- `carrinho.html` — página do carrinho de compras
- `estilo.css` — estilos da página principal
- `carrinho.css` — estilos do carrinho
- `script.js` — funcionalidades e interações do sistema
- `imagem/` — imagens utilizadas no projeto
